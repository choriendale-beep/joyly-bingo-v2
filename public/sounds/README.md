# Bingo Sound Files (የቢንጎ ድምፅ ፋይሎች)

Place your number audio files (.mp3 or .wav) in this folder:

Examples:
- `1.mp3`, `2.mp3`, `3.mp3`, ..., `75.mp3`
- Or `B1.mp3`, `B2.mp3`, ..., `O75.mp3`

When a ball is called in the game (e.g., number 15 or B12), the application automatically plays the matching audio file from `/sounds/[number].mp3` or `/sounds/[letter][number].mp3` synchronized with the number call!

You can also upload your desktop sound files directly through the app UI using the Sound Settings modal!
